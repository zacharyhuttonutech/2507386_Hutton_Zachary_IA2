**Course Title:** CIT2011 - Web Programming
**Assignment Due Date:** Week 9
**Technologies Required:** HTML5, CSS3, Native JavaScript (ES6+)

**Student:** Zachary Hutton (2507386)

## About

A three page registration site for the Coding Conf event. The user fills in the registration form on the login page, the details are saved in localStorage, and ticket.html builds the ticket from the saved details.

## Pages

- `index.html` - home page with the event details and a Register Now link
- `login.html` - registration form with JavaScript validation
- `ticket.html` - the generated ticket

## Folders

- `css/` - style.css
- `js/` - validation.js and ticket.js
- `assets/images/` - the images from the starter pack

## Running it

Open `index.html` in a browser.
